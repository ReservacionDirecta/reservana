# Recomendación de nombres — Beach Club PMS (extensión Hothelia)

Contexto: Hothelia = PMS agentic; producto = gestión de áreas (butacas) en playa, reservas, consumo, QR, mapa en vivo. Usuario prefiere nombres funcionales, no poéticos exagerados; precisión > estética.

## Recomendación principal: **Hothelia Beach**
Razón: hereda confianza del PMS padre; no confunde; indica claramente el nicho. Fácil de recordar para hoteleros que ya conocen Hothelia. Subdominio lógico: `beach.hothelia.com`.

## Alternativas clasificadas (con opinión)

| Nombre | Tipo | Por qué funciona | Riesgo / Nota |
|---|---|---|---|
| **Hothelia Beach** | Marca derivada | Herencia directa; confianza inmediata | Ninguno serio |
| **Otelia Beach** | Marca derivada (Otelia = PMS actual) | Si el producto padre es Otelia.com, esta es la extensión natural | Evita confundir con Hothelia si son marcas separadas |
| **Hothelia Club** | Funcional | Cubre clubs de playa sin limitar a playa; escalable a clubs de montaña/pool | Menos específico para Margarita |
| **Vitrina** | Conceptual (escaparate) | Corto, visual, evoca "exhibir áreas disponibles"; suena como producto independiente | No lleva la marca Hothelia; requiere más marketing |
| **Butaca** / **Butaca Pro** | Funcional (objeto clave) | Nombra directamente lo que se gestiona: la butaca/área; memorable para el personal del club | Puede sonar pequeño; evitar si se apunta a grandes grupos familiares |
| **Mapa Mar** / **MarMap** | Funcional (mapa + mar) | Destaca la función diferenciadora: mapa interactivo en la arena | Poco relacionado con PMS; suena a app de navegación |
| **Playa QR** / **Playa QR Pro** | Funcional (QR + playa) | Enfatiza el flujo del huésped: escanea en la butaca | Muy literal; puede parecer un servicio de códigos QR solamente |
| **Isla** | Local / Caribeño | Evoca Margarita directamente; corto, fácil de pronunciar | Genérico; no comunica gestión ni reservas |
| **Arena** | Conceptual | Directo: "gestiona lo que pasa en la arena"; fuerte para branding local | No indica tecnología; puede confundirse con arena física |

## Mi opinión clara (recomendada para inversión)
Usa **Otelia Beach** si Otelia.com es la plataforma padre activa hoy; usa **Hothelia Beach** si Hothelia es la marca pública dominante. El sufijo "Beach" define el nicho sin perder la herencia.

Evita nombres completamente nuevos (Vitrina, Isla, Arena) si el objetivo es vender confianza a clubs que ya conocen el PMS padre; una marca independiente requiere más presupuesto de marketing (ver pitch: $600 de marketing inicial). Si el objetivo es lanzar como producto autónomo con su propio modelo de suscripción, entonces **Vitrina** es la mejor opción independiente.

## Sugerencia de estructura de dominio
- Principal: `oteliabeach.com` o `hothelia.com/beach`
- App del huésped (QR): `qr.oteliabeach.com` o subdominio del club: `clubnombre.oteliabeach.com`


## Confirmación del usuario (2026-09-28)
Nombres preferidos: `clubhub`, `club.app`, `reservana.com.ve`, `reservata`.
Recomendación aplicada: `Reservana` (dominio `.com.ve` por localización Margarita; más funcional que `clubhub` o `club.app`).

## Comparación de los 4 propuesta del usuario

| Nombre | Veredicto | Por qué |
|---|---|---|
| `clubhub` | Descartar | Genérico; no indica reservas ni mapa de áreas. |
| `club.app` | Descartar | Funciona como categoría, no como marca; no comunica valor específico. |
| `reservana.com.ve` | **Recomendado** | Dominio `.com.ve` = Venezuela/Margarita; "Reservana" = reservas + playa; claro para inversionistas locales; funciona con el pitch actual. |
| `reservata` | Aceptable | Corto, internacional, pero sin el dominio local ni la claridad del sufijo "-ana" (que evoca playa/isla). |
